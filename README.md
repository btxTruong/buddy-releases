# buddy-releases

Public distribution repo for **[buddy](https://github.com/btxTruong/buddy)** — a macOS menu bar translator.

## Install

Grab the latest signed + notarized DMG from **[Releases](https://github.com/btxTruong/buddy-releases/releases/latest)**.

1. Open the DMG.
2. Drag **buddy.app** into Applications.
3. Launch from Applications or Spotlight.

## Updates

The app self-updates via [Sparkle](https://sparkle-project.org/). New versions arrive automatically; you can force a check via the menu bar → **Check for Updates…**.

Appcast feed: <https://btxTruong.github.io/buddy-releases/appcast.xml>

## Verification

Every release is code-signed with an Apple Developer ID (Team `G3PM73FMZ3`) and notarized by Apple. Requires macOS 15 Sequoia or later.
